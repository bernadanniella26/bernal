# WorkFlow Portal Mock UI

A minimal, responsive front-end that mimics the layout in the provided screenshot: left sidebar for case folders, top toolbar with filters/search, and a main cases table with sorting, filtering, and search.

## Run locally

Open the `index.html` file with any static server.

- Python 3: `python3 -m http.server 8080` from this directory, then open `http://localhost:8080`.
- VS Code/Cursor: use the Live Server extension.

## Files

- `index.html` – page structure
- `styles.css` – layout and styling
- `script.js` – mock data, sorting, filtering, search, sidebar toggle
